# DIVINE ARSENAL 3D 모델 팩

- longinus: 붉은 쌍갈래 신창, 장식된 창대와 발광 보석
- babylon: 황금 원형 포탈 유물, 다중 동심원과 중심 보석
- apollo: 황금 태양 활, 곡선 활대와 태양 문양

실제 Minecraft 아이템 JSON cuboid 모델과 128x128 전용 텍스처가 프로젝트에 통합되어 있습니다.
기존 Forge 소스의 아이템 모델 JSON을 교체했습니다. 모델은 Blockbench에서 Java Block/Item 모델로 불러와 수정할 수 있습니다.
주의: 무기의 거대 낙하 연출이나 발사체 자체의 3D 엔티티 렌더러는 포함하지 않습니다. 게임 내 빌드 검증은 수행하지 못했습니다.
