# DIVINE ARSENAL v0.4.0: 연출 구현

- 롱기누스: 나선형 쌍날과 긴 창대가 하강하는 입자 형상, 충격파, 광역 피해.
- 바빌론: 3중 회전 마법진 36개, 세로 광선, 연쇄 폭발과 범위 피해.
- 아폴론: 위도별 불꽃 고리로 구성한 구체형 태양, 하강, 폭발과 광역 피해.
- 설정 `terrainDestruction` 기본 false. true일 때 폭발이 지형을 손상할 수 있음.
- 동시 사용 상한 8개. 입자 밀도 설정 가능.

## 현재 한계
초대형 창과 태양은 **전용 3D 엔티티 모델이 아니라 파티클로 구현된 입체 연출**입니다.
실제 게임 내 빌드 및 렌더링 테스트는 수행하지 못했습니다. ForgeGradle 다운로드가 가능한 환경에서 빌드해야 합니다.
